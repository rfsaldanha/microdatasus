# Municipalities table

Municipalities table

## Usage

``` r
tabMun
```

## Format

A data frame with 5659 rows and 2 variables:

- munResCod:

  Municipality IBGE code with 6 numbers

- munResStatus:

  Status

- munResTipo:

  Type

- munResNome:

  Name

- munResUf:

  UF (state)

- munResLat:

  Latitude

- munResLon:

  Longitude

- munResAlt:

  Altitude

- munResArea:

  Area
